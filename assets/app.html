🟢 开启实时捕获 Fiddler 推送模式：工具启动接收服务，Fiddler 负责抓包
浏览器 / App 把 HTTP 代理指向 127.0.0.1:9091 即可抓包。HTTPS 仅能记录连接元数据（域名/状态/耗时），无法解密 body。
说明：上游代理留空则直连目标；若目标域名需经 VPN（Clash/SakuraCat/其他）才能访问，填该工具的代理地址即可，助手不绑定任何特定软件。
工作原理：本工具不直接抓包，而是接收 Fiddler 抓到的请求。浏览器 / App 仍然走 Fiddler 代理（默认 127.0.0.1:8888），由 Fiddler 通过 CustomRules 实时把每个完成的 session POST 到本工具。
配置步骤：
  1. 点击上方按钮，看到顶部状态变为「代理运行中」。
  2. 打开 Fiddler，进入 Rules → Customize Rules（快捷键 Ctrl+R）。
  3. 找到 OnDoneResponse 函数，在函数末尾粘贴下方的脚本。
  4. 保存 CustomRules，Fiddler 会自动重载脚本。
  5. 在浏览器 / App 中正常操作，请求会自动出现在「抓包会话」页。
Fiddler CustomRules 脚本 
import System.Net;

static function OnDoneResponse(oSession: Session) {
    if (oSession.isTunnel) return;

    var payload = {
        method: oSession.RequestMethod,
        url: oSession.fullUrl,
        status_code: oSession.responseCode,
        request_body: '',
        response_body: '',
        trace_id: ''
    };
    try { payload.request_body = oSession.GetRequestBodyAsString(); } catch(e) { payload.request_body = ''; }
    try { payload.response_body = oSession.GetResponseBodyAsString(); } catch(e) { payload.response_body = ''; }
    if (oSession.oRequest.headers.Exists('x-trace-id')) {
        payload.trace_id = oSession.oRequest.headers['x-trace-id'];
    } else if (oSession.oRequest.headers.Exists('trace-id')) {
        payload.trace_id = oSession.oRequest.headers['trace-id'];
    }

    try {
        var wc = new System.Net.WebClient();
        wc.Headers.Add('Content-Type', 'application/json');
        wc.UploadString('http://127.0.0.1:9090/ingest', 'POST', Fiddler.WebFormats.JSON.JsonEncode(payload));
    } catch(e) {
        // 推送失败时静默忽略，避免阻塞 Fiddler
    }
}
  1. 在上方「捕获方式」选择 本地代理抓包（9091）。
  2. （可选）设置域名过滤：白名单只抓指定域名，黑名单排除指定域名。
  3. 点击上方「● 开始实时捕获」，工具在 127.0.0.1:9091 启动本地代理。
  4. 将浏览器 / App 的 HTTP 代理设置为 127.0.0.1:9091（HTTPS 需在系统/应用代理里也指向它）。
  5. 正常操作，HTTP 请求（含 body）会实时进入「抓包会话」页；HTTPS 仅记录连接元数据。
本地代理为纯标准库实现，HTTPS 走 CONNECT 隧道不解密 body。如需 HTTPS 完整请求/响应体，仍建议使用 Fiddler 推送模式。
